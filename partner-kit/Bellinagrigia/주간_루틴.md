# 주간 루틴 — 하루 1시간, 요일마다 정해진 것만

고민하는 시간이 제일 아깝습니다. 요일별로 정해진 명령어만 실행하세요.
(명령어 번호는 `명령어_모음.md` 기준)

| 요일 | 할 일 (1시간) | 쓰는 명령어 |
|------|--------------|------------|
| **월** | 인스타 일주일 계획 + 오늘 게시물 1개 올리기 | 3번 → 2번 |
| **화** | 아티클 1개 써서 관리자 페이지에 발행 | 4번 |
| **수** | 인스타 게시물 1개 (사진 있으면 5번, 없으면 2번) | 2번 or 5번 |
| **목** | 와츠앱 문의 답장 정리 + 업체 소통 밀린 것 | 7번, 9번 |
| **금** | 인스타 릴스/스토리 1개 + 이번 주 사진 정리 | 2번, 6번 |
| 주말 | 쉬기 (또는 파티·모임에서 사진만 찍어두기) | 6번 |

## 매일 5분 습관
- 와츠앱 문의 온 것 → 명령어 7번으로 답장
- 사이트 관리자 대시보드 한 번 열어서 대기명단 숫자 확인

## 이번 달 목표 (이것만 보면 됨)
- 인스타 주 3회 꾸준히 = 월 12개
- 아티클 주 1회 = 월 4개
- 대기명단 + 와츠앱 문의 쌓이는 것 확인

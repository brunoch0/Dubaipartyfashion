# 복붙 명령어 5개 — 이것만 쓰면 됩니다

Claude 채팅창에 아래 문장을 그대로 붙여넣으세요. [ ] 부분만 바꾸면 됩니다.

## 1. 오늘 뭐하지 (막막할 때)
```
오늘 1시간 있어. 브랜드에 제일 도움되는 것 하나만 골라서 같이 해줘.
```

## 2. 인스타 게시물
```
인스타 게시물 1개 만들어줘. 주제: [예: 새틴 드레스 소재 이야기]. 사진 설명: [예: 거울 셀피]. 캡션(영어+한국어)과 첫 댓글 해시태그까지.
```

## 3. 아티클 (블로그)
```
사이트에 올릴 아티클 써줘. 주제: [예: 두바이 저녁 모임 드레스코드]. 제목/요약/본문(영어) 순서로, 관리자 페이지에 붙여넣게 나눠서 줘.
```

## 4. 와츠앱 답장
```
고객이 와츠앱으로 이렇게 물어봤어: "[고객 메시지 붙여넣기]". 브랜드 톤으로 영어 답장 써줘.
```

## 5. 사진 → 콘텐츠
```
(사진 첨부하고) 이 사진으로 인스타에 올릴 만한 아이디어 3개와 캡션 줘.
```

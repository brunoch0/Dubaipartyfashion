## 🌅 시작

**1. 오늘 뭐하지 (막막할 때 — 제일 많이 쓰게 될 명령)**
```
오늘 1시간 있어. 브랜드에 제일 도움되는 것 하나만 골라서 같이 해줘.
```

## 📱 콘텐츠 (인스타·아티클)

**2. 인스타 게시물**
```
인스타 게시물 1개 만들어줘. 주제: [예: 새틴 드레스 소재 이야기]. 사진 설명: [예: 거울 셀피]. 캡션(영어+한국어)과 첫 댓글 해시태그, 와츠앱 주문 유도 문구까지.
```

**3. 인스타 일주일치 계획**
```
이번 주 인스타 3개(피드2, 릴스1) 계획 짜줘. 내가 가진 사진: [예: 드레스 사진 2장, 원단 사진 1장]. 각각 주제/캡션/올릴 요일까지.
```

**4. 아티클 (블로그)**
```
사이트에 올릴 아티클 써줘. 주제: [예: 두바이 저녁 모임 드레스코드]. 제목/요약/본문(영어) 순서로, 관리자 페이지에 붙여넣게 나눠서 줘.
```

**5. 사진 → 콘텐츠**
```
(사진 첨부하고) 이 사진으로 인스타에 올릴 만한 아이디어 3개와 캡션 줘.
```

**6. 오늘 찍어둘 사진 (콘텐츠 재료 쌓기)**
```
오늘 [예: 샘플 업체 방문] 하는 날이야. 나중에 브랜드 스토리 콘텐츠로 쓰게 찍어둘 사진/영상 목록 알려줘. 얼굴 안 나오게.
```

## 💬 판매 (와츠앱)

**7. 고객 문의 답장**
```
고객이 와츠앱으로 이렇게 물어봤어: "[고객 메시지 붙여넣기]". 브랜드 톤으로 영어 답장 써줘. 가격은 [예: AED 420], 수령 방법은 [예: 두바이 직접 전달].
```

**8. 판매 안내 기본 세트 (한 번만 만들어두고 계속 사용)**
```
와츠앱 판매용 기본 문구 세트 만들어줘: ①첫 인사+상품 소개 ②사이즈/가격 안내 ③주문 확정+결제 안내 ④전달/배송 안내 ⑤구매 후 감사+후기 요청. 영어로, 각각 3문장 이내.
```

## 🏭 업체 소통

**9. 제작 업체 요청사항 정리**
```
제작 업체에 보낼 요청을 정리해줘. 내가 원하는 것: [예: 제작 과정 사진 단계마다 3장씩, 납기 10월 말 확정]. 오해 없게 번호 매겨서, 정중하지만 명확하게.
```

**10. 마케팅 업체 검수**
```
마케팅 업체가 이런 시안/결과를 보냈어: [내용 붙여넣기 또는 캡처 첨부]. 우리 브랜드 톤(절제된 럭셔리, 과장 금지)에 맞는지 점검하고, 수정 요청 문구 써줘.
```

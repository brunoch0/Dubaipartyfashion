## 2. AI(Claude) 쓰는 법 — 기본기

유선님의 AI 사용 목표: **"Bruno 없이도 막힌 걸 스스로 푸는 것"**

### 시작하기
1. https://claude.ai 접속 → 구글 계정으로 가입 (무료로 시작 가능)
2. 새 대화를 열고, **맨 처음에 아래 "프로젝트 소개문"을 붙여넣기** — 이걸 해야 AI가 우리 상황을 알고 답합니다

### 📋 프로젝트 소개문 (새 대화마다 맨 앞에 복붙)
```
나는 두바이에서 패션·커뮤니티 라이프스타일 브랜드 "Bellinagrigia"를 운영하는 창업자야.
- 웹사이트: https://dubaipartyfashion.vercel.app (영어 기본, 한국어/아랍어 지원)
- 사이트 관리는 관리자 페이지(어드민)에서 내가 직접 해: 아티클(블로그), 이벤트, 룩북(사진), SNS 링크, 사이트 문구 수정 가능
- 개발자가 아니라서 기술 용어는 쉽게 설명해줘
- 브랜드 톤: 절제된 고급스러움, "뷰티풀한 회색", 과장 없는 카피
질문: [여기에 질문]
```

### 질문 잘하는 법 3가지
1. **상황+목표+막힌 지점**을 같이 말한다. ("아티클을 쓰는데 → SEO에 좋게 쓰고 싶어 → 제목을 어떻게 뽑을지 모르겠어")
2. **스크린샷을 붙인다.** 화면이 이상하면 캡처해서 올리고 "이 화면에서 뭘 눌러야 해?"
3. **결과물이 마음에 안 들면 그대로 말한다.** "너무 광고 같아, 더 담백하게" — AI는 고쳐달라면 계속 고쳐줍니다

## 3. 직접 하기 — 멈춰있는 것들 실행 가이드

### 3-1. 도메인 구매 (30분, 유선님 명의로!)
1. https://www.namecheap.com 또는 https://porkbun.com 가입 (**유선님 이메일로**)
2. 원하는 주소 검색 — 추천 후보: `bellinagrigia.com` (연 $10~15 수준)
3. 구매 후 Bruno에게 "샀어요"라고 알려주면 사이트 연결은 Bruno가 처리
- 막히면 AI에게: **"Namecheap에서 도메인 사는 방법 단계별로 알려줘. 결제까지."**

### 3-2. 사이트 콘텐츠 채우기 (어드민에서, AI와 함께)
사이트의 글과 사진이 전부 임시입니다. 우선순위:
1. **브랜드 소개/창업자 메시지** — 어드민 → 사이트 문구. AI에게: *"내 브랜드 스토리를 말해줄게: [이야기]. 이걸 브랜드 소개 3문단으로 다듬어줘. 영어 번역도."*
2. **아티클 2~3개** — 어드민 → 아티클 → 새로 만들기. AI에게: *"두바이에서 파티 갈 때 옷 고르는 법을 주제로 블로그 글을 써줘. 검색에 잘 걸리게 제목/요약도. 영어와 한국어 둘 다."* → 결과를 복사해서 English/한국어 탭에 붙여넣기 → 상태 "공개" → 저장
3. **이벤트 등록** — 다음 브런치/네트워킹 파티를 어드민 → 이벤트에 등록 (모집중 상태). 신청자는 RSVP 메뉴에 쌓입니다
4. **사진 교체** — 룩북/아티클의 임시 사진을 실제 사진으로 (이미지 필드 "파일 업로드" 버튼). 팁: 브랜드 톤은 흑백입니다 — 컬러 사진 올려도 사이트가 자동으로 흑백 처리하니 그냥 올리면 됩니다
5. **SNS 링크 실제 주소로** — 어드민 → SNS/링크 → 인스타/스냅챗 URL 수정

### 3-3. 인스타 콘텐츠 (AI 활용)
- AI에게: *"이번 주 인스타 피드 3개 기획해줘. 브랜드 톤은 절제된 럭셔리, 흑백 사진 기반. 각 게시물의 사진 아이디어 + 캡션(영어) + 해시태그."*
- 개인 계정 + 브랜드 계정 **공동 게시(Collab)** 기능 활용 — 인스타 게시 화면에서 "태그 → 공동 작업자 초대"

### 매주 루틴 제안 (30분)
어드민 대시보드 열기 → 대기명단/RSVP 숫자 확인 → 아티클 1개 발행 → 인스타 2회 예약. 이것만 돌아가면 사이트는 살아있습니다.

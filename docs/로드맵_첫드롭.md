# Bellinagrigia 첫 드롭 로드맵 (소량 제작·판매 기준)

작성: 2026-09-16 · 기준: 첫 컬렉션 **50장 한정 선판매 → 제작 → 배송**

> 핵심 설계: 만들어놓고 파는 게 아니라 **선판매로 수요를 먼저 확인**하고 제작한다.
> 재고 리스크 0에 가깝게, 희소성("50장 한정")은 마케팅 무기로.

---

## 전체 흐름 (약 10~12주)

```
Phase A 기반 정리 → Phase B 선판매 준비 → Phase C 선판매 오픈(2주) → [게이트] → Phase D 제작·배송 → Phase E 확장 판단
```

**목표 숫자 (거꾸로 계산):**
- 첫 드롭 50장 완판 ← 선판매 전환율 ~25% 가정 ← **대기명단 200명** ← 인스타 팔로워/도달로 유입
- 그래서 Phase A~B의 콘텐츠 목표는 매출이 아니라 **대기명단 200명**

---

## Phase A — 기반 정리 (지금 ~ 2주)

| 트랙 | 할 일 | 담당 |
|------|------|------|
| 개발 | 도메인 연결 · 법적 페이지(개인정보/약관/환불정책) + 사업자 표기 · PG 결정 및 계약 신청(심사 기간 감안해 지금) · sitemap/robots | Bruno |
| 제조 | 샘플 업체 최종 확정 · 첫 상품 1종 확정(디자인·소재·컬러) · 원가/납기 확정 · 사이즈 스펙(S/M/L 실측표) | 파트너 |
| 콘텐츠 | 브랜드 인스타 계정 정비(프로필/하이라이트) · 사이트 placeholder 콘텐츠를 실제로 교체(브랜드 소개·창업자 메시지) · 첫 아티클 1개 발행(인수인계 1단계 겸) | 파트너+AI |

**Phase A 완료 기준:** 도메인으로 사이트 접속 + 샘플 1벌 확보 + 인스타에 브랜드 게시물 3개

## Phase B — 선판매 준비 (2주 ~ 6주)

| 트랙 | 할 일 | 담당 |
|------|------|------|
| 개발 | **선판매 MVP**: 상품 페이지(50장 카운터) + 결제 + 주문 어드민 + 주문 확인 메일 · 사전예약 섹션→선판매 카운트다운 연결 | Bruno |
| 제조 | 샘플 피팅/수정 · 본생산 계약 조건 확정(선판매 종료 후 발주 전제, 리드타임 몇 주인지 명문화) · 패키징(박스/네임태그 — 로고 벡터 필요) | 파트너 |
| 콘텐츠 | **주간 루틴 가동**: 아티클 주1(SEO) + 인스타 주3(피드2·릴스1) · AI 스튜디오컷으로 상품 화보 세트 제작 · 메이킹 필름 축적 · 대기명단 캠페인("가입자에게 24시간 먼저 오픈+얼리버드가") | 파트너+AI |

**Phase B 완료 기준:** 결제 테스트 통과 + 대기명단 150명+ + 상품 화보/상세페이지 완성

## Phase C — 선판매 오픈 (2주간)

| 트랙 | 할 일 |
|------|------|
| 개발 | 오픈 직전 점검(보안·에러감시·결제 리허설) · 오픈 후 대시보드로 전환 모니터링 |
| 제조 | 대기 (판매량 확정 전 발주 금지) |
| 콘텐츠 | D-7 티저 → D-1 대기명단 선오픈 → D-day 공개 → 매일 잔여 수량 스토리("34/50") · **오프라인 런칭 파티 연계**(자택 네트워킹 — RSVP 페이지 활용, 현장 QR 주문) |

### 🚦 판단 게이트 (선판매 2주 종료 시점)
| 결과 | 판단 |
|------|------|
| 40장+ (80%↑) | **Scale** — 본생산 발주 + 2차 드롭 기획 착수 |
| 20~39장 | **Continue** — 발주 진행, 마케팅 채널 재점검 후 잔여 판매 연장 |
| 20장 미만 | **Pivot** — 발주 보류. 가격/디자인/타겟 중 뭐가 문제인지 대기명단 대상 설문 후 재설계 |

## Phase D — 제작·배송 (게이트 통과 후 4~6주)

| 트랙 | 할 일 |
|------|------|
| 개발 | 주문 상태 관리(제작중→배송중 메일) · 후기 수집 폼 |
| 제조 | 본생산 발주 → 중간 QC → 검수 → 패키징 → 두바이 시내 배송(방법: 직접/라스트마일 업체 결정) |
| 콘텐츠 | "제작 과정" 시리즈(공장·QC 비하인드 = 신뢰 콘텐츠) · 배송 시작하면 언박싱 유도(패키지에 해시태그 카드) · 구매자 착장 리그램 |

## Phase E — 확장 판단 (드롭 완료 후)

- 데이터 리뷰: 전환율, 유입 채널별 성과(UTM), 재구매 의향
- 결정: 2차 드롭 품목(파티복 확장?) · 풀 쇼핑몰 구축 여부 · 플랫폼 입점 시작 여부
- 인수인계 4단계(독립 운영) 병행 — 이 시점부터 Bruno는 개발+리뷰만

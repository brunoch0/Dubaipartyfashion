# Bellinagrigia 첫 드롭 로드맵 v2 (인스타→와츠앱 직접판매)

작성: 2026-09-16 · 수정: 같은 날 (판매 채널 단순화 결정)

> **v2 핵심 결정: 첫 판매는 홈페이지 결제 없이 진행한다.**
> 인스타그램 → 와츠앱 DM 대화 → 직접 판매(계좌이체/현장). 결제 시스템·주문 관리·PG 전부 보류.
> 홈페이지 역할 = SEO 아티클 + 브랜드가 만들어지는 스토리 아카이브 (가볍게).

---

## 판매 플로우

```
인스타 게시물/스토리 → "DM 또는 와츠앱으로 주문" → 와츠앱 대화 (사이즈·수령 방법 안내)
→ 결제(계좌이체/현금/결제링크) → 직접 전달 or 배송 → 착장 후기 리그램
```

**이 방식의 이점:** 고객 한 명 한 명과 대화 = 가격·핏·취향 데이터가 그대로 쌓임 · 결제 시스템 구축/PG 심사 0주 · 두바이 로컬 상거래 관행(와츠앱 주문)과 일치 · 50장 규모에선 수작업이 오히려 빠름

**전환 기준:** 와츠앱 주문이 **월 30건+ 반복**되어 수작업이 병목이 되면 그때 홈페이지 결제 구축 (그 전엔 안 만든다)

---

## 전체 흐름 (약 8~10주)

### Phase A — 기반 정리 (지금 ~ 2주)

| 트랙 | 할 일 | 담당 |
|------|------|------|
| 개발 | 도메인 연결 · 사이트 CTA를 와츠앱으로 전환(어드민 데이터 수정으로 가능, 코드 변경 없음) · sitemap/robots(SEO) · 개인정보처리방침 라이트(폼 수집용) | Bruno |
| 제조 | 샘플 업체 확정 · 첫 상품 확정 · 원가/납기 · 사이즈 실측표 | 파트너 |
| 콘텐츠 | 인스타 프로필 정비(바이오에 와츠앱 링크) · 와츠앱 비즈니스 계정 세팅(인사말·카탈로그 기능) · 사이트 브랜드 스토리 실제 콘텐츠로 교체 | 파트너 |

### Phase B — 판매 준비 (2 ~ 5주)

| 트랙 | 할 일 | 담당 |
|------|------|------|
| 개발 | (거의 없음) 아티클 발행 지원 · 대기명단→와츠앱 안내 연결 | Bruno |
| 제조 | 샘플 피팅/수정 · 본생산 조건 확정(주문량 확인 후 발주 전제) · 패키징 | 파트너 |
| 콘텐츠 | **주간 루틴**: 아티클 주1(SEO — "브랜드 만드는 이야기" 시리즈 포함) + 인스타 주3 · AI 화보 세트 · 메이킹 필름 · 와츠앱 주문 스크립트 준비(가격·사이즈 안내 문구, AI로 작성) | 파트너+AI |

### Phase C — 판매 오픈 (2주)

- 인스타 공개 → 스토리 매일("00/50 남음") → 와츠앱 대화 → 주문 장부 기록(스프레드시트면 충분)
- 오프라인 런칭 파티 연계 — 현장 착용·주문 (RSVP는 사이트 이벤트 기능 활용)

### 🚦 판단 게이트 (2주 종료)
| 결과 | 판단 |
|------|------|
| 40건+ | **Scale** — 본생산 발주 + 2차 드롭 + 이때 홈페이지 결제 구축 검토 시작 |
| 20~39건 | **Continue** — 발주, 채널 재점검 후 연장 판매 |
| 20건 미만 | **Pivot** — 발주 보류, 와츠앱 대화 로그에서 이유 찾기(가격? 핏? 타이밍?) |

### Phase D — 제작·전달 (4~6주)
- 제조: 발주 → QC → 패키징 → 직접 전달/배송
- 콘텐츠: 제작 비하인드 시리즈 → 언박싱/착장 리그램 → 후기 축적
- 개발: 없음 (아티클만 계속)

### Phase E — 확장 판단
- 와츠앱 대화 로그 리뷰 = 고객 리서치 결과물
- 결정: 2차 드롭 · 홈페이지 결제 필요 여부(월 30건 기준) · 플랫폼 입점
